#### 🚀 Featured projects

**[judgenot0](https://github.com/cy-r0x/judgenot0)**: a full online judge for programming contests, split into three services:

| Service | What it does | Stack |
|---|---|---|
| [JudgeServer](https://github.com/cy-r0x/JudgeServer) | Auth (RBAC + JWT), problem setting, submissions, real-time contest standings | Go · PostgreSQL · GORM |
| [JudgeEngine](https://github.com/cy-r0x/JudgeEngine) | Compiles and runs submissions in an `isolate` sandbox with cgroup resource limits | Go · RabbitMQ · Prometheus |
| [JudgeClient](https://github.com/cy-r0x/JudgeClient) | Contest UI with code editor and math-aware problem statements | Next.js · React · CodeMirror |

**[rag-vector-engine](https://github.com/cy-r0x/rag-vector-engine)**: multi-tenant RAG-as-a-service. Ingests PDFs, DOCX, XLSX, CSV and images (with OCR), indexes them into tenant-isolated vector partitions, and streams answers over WebSockets.
`FastAPI` · `RabbitMQ` · `PostgreSQL` · `Redis` · `MinIO`
